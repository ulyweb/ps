Collection Guide

Export Filtered Events from Event Viewer (XML)

click to collapse/expand
  1. Open Event Viewer: Windows key → type Event Viewer → Enter.
  2. Choose a log: Windows Logs → Application / System / Security / Setup.
  3. Filter: Right pane → Filter Current Log… → enter Event IDs (example: 1000,1002 or 37,41,6008).
  4. Time window (recommended): Logged → Last 24 hours / Last 7 days.
  5. Export: Right-click the log → Save Filtered Log File As… → select XML → save.
  6. Import here: Use the Import card below, then click Generate Analysis.
